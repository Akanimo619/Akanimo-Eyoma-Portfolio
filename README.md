# Akanimo Eyoma — Portfolio

A polished static portfolio combining selected Business Intelligence projects and two applied Machine Learning applications.

## Included

- 2 Power BI projects with dashboard screenshots and `.pbix` files
- 4 Tableau projects with `.twb` files; screenshots are available for Product Sales, Office Supply and Vrinda Store
- 2 applied ML projects: Nigeria Crime Risk Classification and College Placement Prediction
- Project source files and project-specific README files
- Responsive HTML/CSS/JavaScript portfolio site

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace `YOUR_LINKEDIN_URL` and `YOUR_GITHUB_URL` in `index.html`.
3. Add your final CV as `assets/cv.pdf` and add a Resume button if desired.
4. Add a profile photo if you want one.
5. If you later obtain a Food & Beverage dashboard screenshot, replace the abstract preview in the Food & Beverage card.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local static server.

## Portfolio positioning

The site intentionally positions Business Intelligence/Data Analytics as the primary professional focus, with Machine Learning presented as an expanding applied skill set. The College Placement project includes its trained KNN model and categorical encoder artifacts, so the Streamlit application can be run locally from the supplied project folder.
